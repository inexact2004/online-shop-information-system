# Online Shop Information System

## Project Overview
This project is an Online Shop Information System developed as part of the **Software Development Methodologies** course.
The system allows users to browse products, manage a shopping cart, place orders, and simulate online payments.

## Methodology
The project was developed using the **Scrum methodology**. The work was divided into multiple sprints, and weekly meetings were held to review progress and plan upcoming tasks. **Trello** was used to track tasks and monitor development progress.

## Technologies Used
- Backend: Node.js (Express)
- Frontend: HTML, CSS, JavaScript
- Database: MySQL
- API Style: REST
- Version Control: Git & GitHub
